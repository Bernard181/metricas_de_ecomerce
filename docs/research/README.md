# Pesquisas

Esta pasta reúne pesquisas e estudos realizados para o CloudOps.

## Objetivo

Documentar investigações, benchmarks e estudos que fundamentam decisões sobre:

- fontes de dados e integrações (vendas, anúncios, estoque, financeiro);
- métricas e KPIs de e-commerce;
- arquitetura e tecnologia;
- padrões de mercado.

## Formato

Cada pesquisa deve ser documentada em um arquivo Markdown com objetivo, descobertas e recomendações.

## Estudos

- [`tech-stack.md`](tech-stack.md) — avaliação da stack do backend (fundamenta ADR-0004).
- [`kpis.md`](kpis.md) — KPIs de e-commerce considerados para o engine de métricas.
- [`origem-requisitos-e-contexto.md`](origem-requisitos-e-contexto.md) — requisitos e contexto originais que deram origem à estrutura e às regras do projeto (conteúdo incorporado em `AGENTS.md`).
- [`pitch-original-cloudops.md`](pitch-original-cloudops.md) — pitch original da startup (conteúdo incorporado em `README.md`).
