# Decisões de Arquitetura (ADRs)

Nesta pasta ficam registradas as decisões arquiteturais do projeto (Architecture Decision Records).

## Formato

Cada decisão deve ser documentada em um arquivo com o formato:

```
000X-titulo-da-decisao.md
```

Exemplo:

```
0001-usar-rest-para-api.md
```

## Template

Use o template abaixo para registrar uma nova decisão:

---

# Decisão 000X: [Título]

- **Data:** YYYY-MM-DD
- **Status:** Proposta | Aceita | Depreciada | Substituída

## Contexto

[Descreva o problema e o contexto que motiva a decisão.]

## Decisão

[Descreva a decisão tomada.]

## Consequências

- **Positivas:** [o que melhora]
- **Negativas:** [trade-offs aceitos]

## Alternativas consideradas

- [Alternativa 1]
- [Alternativa 2]

---

## Registros

- Nenhuma decisão formal registrada ainda.
